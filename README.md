GCE A/L 2020 Dataset Profiling & Data Cleansing focuses on analyzing and preparing the Sri Lankan G.C.E. Advanced Level 2020 examination dataset for further data warehousing activities.

The work begins with data profiling, where the dataset is examined to understand its structure, columns, data types, missing values, duplicate records, unique values, numerical statistics, and categorical distributions. The analysis also identifies the top-performing students based on Z-scores for each stream.

The next stage is data cleansing, where potential data-quality issues such as duplicate records, missing values, inconsistent text values, invalid numerical values, incorrect dates, and inconsistent categorical data are identified and standardized. The cleaned dataset is then saved as a separate file for use in subsequent ETL and data warehouse processes.

Overall, Day 03 establishes a structured pipeline of:

Raw Dataset → Data Profiling → Data Quality Analysis → Data Cleansing → Clean Dataset → Data Warehouse/ETL
